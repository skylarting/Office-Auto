# Office-Auto

Windows Excel 单元格批量汇总工具。

仓库现在提供两个独立程序：

- `ExcelSummary.exe`：从一个或多个工作簿提取指定单元格并生成汇总；
- `ExcelMapper.exe`：把多个来源工作簿的指定单元格映射到多个目标工作簿。

## 功能

- 选择一个 `.xls` / `.xlsx` / `.xlsm` 文件；
- 选择文件夹后确认并批量处理其中全部工作簿；
- 支持手动输入或在表格网格中点击选择需要提取的单元格；
- 默认选择 `A2、C2、A3、C3`，并可一键恢复默认或清空；
- 支持逗号、空格、换行和中英文分号分隔；
- 两种单元格选择方式实时同步；
- 保留真实数值，并复制源单元格数字显示格式；
- 为汇总表全部已用单元格添加内外细边框；
- 可新建独立汇总文件；
- 可生成在最前面带有汇总表的新工作簿副本，原文件始终不修改；
- 文件夹生成独立汇总文件时，自动增加“文件名称”和“Sheet名称”列；
- 自动跳过临时文件及已经生成的汇总文件；
- 支持 `.xlsm`，生成副本时保留 VBA 项目；
- 支持读取旧版 `.xls`；生成带汇总页的副本时自动另存为 `.xlsx`。

## EXE 使用方法

1. 从 GitHub Actions 下载并解压 `ExcelSummary-Windows`；
2. 双击 `ExcelSummary.exe`；
3. 在“数据来源”下拉框中选择“选择一个表格文件”或“选择文件夹中的所有
   表格”，然后点击右侧“浏览”。选择文件夹后会显示找到的 Excel 文件数量，
   并询问是否处理该文件夹下的所有表格；
4. 选择需要提取的单元格，可使用以下任一方式：

   - **手动输入**：填写单元格地址，例如：

   ```text
   I8, J8, L8, I17, J17, L17
   ```

   - **点击选择**：切换到“点击选择”，在带行号、列号的网格中点击单元格。
     再次点击可取消；需要更大范围时可调整显示行数和结束列。网格最多显示
     200 行、AZ 列，更远的地址仍可手动输入。网格上方会完整列出所有已经
     选中的单元格；

   “手动输入”和“点击选择”页签的右上方均提供“恢复默认”和“清空”，
   两种选择方式的内容保持同步。

5. 选择输出方式：

   - **创建新的汇总文件，集中提取指定单元格数据**：单文件生成一个汇总文件；
     文件夹模式将所有工作簿合并到一个汇总文件；
   - **另存为工作簿副本，在首页插入汇总工作表**：为每个源工作簿生成新副本，
     并把汇总表放在新副本最前面。源文件不会被修改；如果表单名称已存在，
     会自动使用新的不重复名称。

   两种方式都会显示输出位置。单文件选择输出文件；批量生成副本时选择输出
   文件夹。

6. 窗口底部始终显示“开始提取”。“处理进度”区域会显示百分比、当前文件和处理状态；
   每次修改数据来源、单元格或输出设置后，进度会自动重置。

> 写入源工作簿会修改原文件，建议提前备份。

## 公式单元格

程序读取 Excel 文件中上次保存的公式计算结果。如果公式结果为空，请先用
Excel 或 WPS 打开源文件、完成计算并保存，再运行本工具。

旧版 `.xls` 生成副本时会转换为 `.xlsx`。工作表中的值和数字显示格式会被
复制，但旧格式公式会使用文件最后保存的计算结果，不会保留为可编辑公式。

## 本地运行

```bash
python -m pip install openpyxl xlrd
python export_summary.py
```

命令行模式仍然可用：

```bash
python export_summary.py "测试数据.xlsx" \
  -o "汇总结果.xlsx" \
  -c "I8,J8,L8"
```

## 测试

```bash
python -m unittest -v
```

## ExcelMapper

`ExcelMapper.exe` 支持：

- 添加多个来源工作簿和多个目标工作簿；
- 手动设置页可一键清空来源工作簿、目标工作簿和全部映射关系；
- 通过“移到目标”和“移到来源”按钮调整工作簿用途；
- 自动读取工作簿中的工作表名称；
- 根据工作簿和工作表的同名或相同前缀自动优先选择目标；
- 手动设置页的工作簿区域与映射关系区域可上下拖动调整；窗口缩小时只压缩
  映射条目列表，操作按钮保持可见；
- 在带固定行号、列号的表格中点击或拖动选择单元格；
- 单元格选择器会显示源 Excel 的普通单元格底色，并用蓝色边框标记已选区域；
- 新增映射时自动采用同名目标工作表，并让写入单元格跟随读取单元格；
- 添加、编辑、复制、删除映射规则；
- 不需要选择映射类型：两边单元格数量相同时按顺序对应，一个来源单元格
  可自动写入多个目标单元格；
- 将多单元格规则展开为逐项的“来源位置 → 目标位置”预览；
- 保存和导入业务人员可直接编辑的 TXT 映射方案；
- “手动设置”和“TXT 方案”是两个完整工作页签；切换页签时自动双向同步，
  不需要再点击转换按钮；
- TXT 页签采用可拖动的左右分栏：左侧编辑方案，右侧固定显示格式示例和填写
  说明，并可一键复制示例；
- 执行前检查文件、工作表、单元格、重复目标和已有内容；
- 为目标工作簿生成新副本，原文件始终不修改；
- 支持 `.xls`、`.xlsx`、`.xlsm`，旧版 `.xls` 副本输出为 `.xlsx`。

工作簿副本会保留目标表原来的布局和单元格样式，只写入映射值，并使用来源
单元格的数字显示格式。

TXT 方案每行表示一条映射，格式为
`【工作簿；工作表；单元格 → 工作簿；工作表；单元格】`：

```text
【来源工作簿.xlsx；来源工作表名称；A1,A2,A3 → 目标工作簿.xlsx；目标工作表名称；A1,A2,A3】
【来源.xlsx；数据；A1,A2 → 目标.xlsx；模板；B1,B2】
【来源.xlsx；数据；B3-B6 → 目标.xlsx；模板；同位置】
```

`同位置`表示写入单元格与读取单元格相同。文件路径可以使用绝对路径，也
可以填写相对于“方案基准文件夹”的相对路径。字段可以使用中文或英文分号；
`B3-B6`、`A1-D1`表示连续范围。输出位置不写入 TXT，默认使用方案基准
文件夹中的“映射结果”文件夹。导入 TXT 时，程序自动把 TXT 所在文件夹设为
基准文件夹。程序内的“格式示例”按钮会把可复制的示例内容与填写说明分开
显示。

从“手动设置”切换到“TXT 方案”时，当前映射会自动生成可编辑的 TXT 内容；
从“TXT 方案”切回“手动设置”时，程序只尝试同步能够解析的内容，不检查文件
或工作表是否可用，也不会用弹窗阻止切换。尚未写完的 TXT 内容会原样保留。
只有点击“预检查”或“开始映射”时，程序才进行完整检查并提示具体错误。

## 构建 Windows EXE

推送到 GitHub 后，`Build Windows EXE` 工作流会在 Windows 环境中运行测试并
生成 `ExcelSummary.exe` 和 `ExcelMapper.exe`。在 Actions 运行页面底部
分别下载 `ExcelSummary-Windows` 和 `ExcelMapper-Windows` 构建产物。
