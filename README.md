# Office-Auto

Windows Excel 单元格批量汇总工具。

仓库现在提供两个独立程序：

- `ExcelSummary.exe`：从一个或多个工作簿提取指定单元格并生成汇总；
- `ExcelMapper.exe`：把多个来源工作簿的指定单元格映射到多个目标工作簿。
- `ExcelMappingSmart.exe`：面向普通业务人员的智能报表生成向导。

## ExcelMappingSmart 小白向导

`ExcelMappingSmart.exe` 与原来的 `ExcelMappingQt.exe` 相互独立，不会改变原工具。
首页只提供“每月生成报表”和“第一次建立方案”两个入口：

- 第一次建立方案：选择方案名称、一份已经正确填写的历史报表，以及该报表对应的
  数据文件夹。程序自动识别工作簿、工作表、多级行列标题和单元格关系，并保存为
  `.smartmap.json` 方案；
- 每月生成报表：选择已保存方案、本月数据文件夹和空白报表模板。程序重新识别
  当月文件，只把不能确定的项目逐项展示给用户确认；
- 确认以“来源工作表 → 目标工作表”为单位，不再逐个确认数百个单元格；确认
  一组工作表后，该组内的行名、列名和数据位置自动批量对应；
- 确认界面同时显示来源数据和目标报表附近区域，并列出部分对应示例，用户只需
  回答“整张表对应”“不对应”或“本次不填写”；
- 默认跳过来源公式和空白值，保护目标报表已有公式，并始终生成报表副本；
- 默认输出到报表模板旁的“映射结果”文件夹，原始数据和模板均不修改。

## 功能

- 选择一个 `.xls` / `.xlsx` / `.xlsm` 文件；
- 选择文件夹后确认并批量处理其中全部工作簿；
- 支持手动输入或在表格网格中点击选择需要提取的单元格；
- 默认选择 `A2、C2、A3、C3`，并可一键恢复默认或清空；
- 支持逗号、空格、换行和中英文分号分隔；
- 两种单元格选择方式实时同步；
- 保留真实数值，并复制源单元格数字显示格式；
- 为汇总表全部已用单元格添加内外细边框；
- 可新建独立汇总文件；
- 可生成在最前面带有汇总表的新工作簿副本，原文件始终不修改；
- 文件夹生成独立汇总文件时，自动增加“文件名称”和“Sheet名称”列；
- 自动跳过临时文件及已经生成的汇总文件；
- 支持 `.xlsm`，生成副本时保留 VBA 项目；
- 支持读取旧版 `.xls`；生成带汇总页的副本时自动另存为 `.xlsx`。

## EXE 使用方法

1. 从 GitHub Actions 下载并解压 `ExcelSummary-Windows`；
2. 双击 `ExcelSummary.exe`；
3. 在“数据来源”下拉框中选择“选择一个表格文件”或“选择文件夹中的所有
   表格”，然后点击右侧“浏览”。选择文件夹后会显示找到的 Excel 文件数量，
   并询问是否处理该文件夹下的所有表格；
4. 选择需要提取的单元格，可使用以下任一方式：

   - **手动输入**：填写单元格地址，例如：

   ```text
   I8, J8, L8, I17, J17, L17
   ```

   - **点击选择**：切换到“点击选择”，在带行号、列号的网格中点击单元格。
     再次点击可取消；需要更大范围时可调整显示行数和结束列。网格最多显示
     200 行、AZ 列，更远的地址仍可手动输入。网格上方会完整列出所有已经
     选中的单元格；

   “手动输入”和“点击选择”页签的右上方均提供“恢复默认”和“清空”，
   两种选择方式的内容保持同步。

5. 选择输出方式：

   - **创建新的汇总文件，集中提取指定单元格数据**：单文件生成一个汇总文件；
     文件夹模式将所有工作簿合并到一个汇总文件；
   - **另存为工作簿副本，在首页插入汇总工作表**：为每个源工作簿生成新副本，
     并把汇总表放在新副本最前面。源文件不会被修改；如果表单名称已存在，
     会自动使用新的不重复名称。

   两种方式都会显示输出位置。单文件选择输出文件；批量生成副本时选择输出
   文件夹。

6. 窗口底部始终显示“开始提取”。“处理进度”区域会显示百分比、当前文件和处理状态；
   每次修改数据来源、单元格或输出设置后，进度会自动重置。

> 写入源工作簿会修改原文件，建议提前备份。

## 公式单元格

程序读取 Excel 文件中上次保存的公式计算结果。如果公式结果为空，请先用
Excel 或 WPS 打开源文件、完成计算并保存，再运行本工具。

旧版 `.xls` 生成副本时会转换为 `.xlsx`。工作表中的值和数字显示格式会被
复制，但旧格式公式会使用文件最后保存的计算结果，不会保留为可编辑公式。

## 本地运行

```bash
python -m pip install openpyxl xlrd xlwt xlutils
python export_summary.py
```

命令行模式仍然可用：

```bash
python export_summary.py "测试数据.xlsx" \
  -o "汇总结果.xlsx" \
  -c "I8,J8,L8"
```

## 测试

```bash
python -m unittest -v
```

## ExcelMapper

`ExcelMapper.exe` 支持：

- 添加多个来源工作簿和多个目标工作簿；
- 来源和目标工作簿列表支持横向及纵向滚动，路径列按实际文字动态调整宽度，
  标题和内容左对齐；
- 页面切换按钮右侧提供统一的“清空所有内容”，可同时清空来源、目标、映射关系、
  Excel 方案和方案基准文件夹；
- 通过“移到目标”和“移到来源”按钮调整工作簿用途；
- 自动读取工作簿中的工作表名称；
- 根据工作簿和工作表的同名或相同前缀自动优先选择目标；
- 手动设置页的工作簿区域与映射关系区域可上下拖动调整；窗口缩小时只压缩
  映射条目列表，操作按钮保持可见；
- 在带固定行号、列号的表格中点击或拖动选择单元格；
- 单元格选择器会显示源 Excel 的普通单元格底色，并用红色粗边框标记已选区域；
- 单元格选择器支持清空、按非空单元格全选/反选，以及一键切换选择公式、
  数值（非公式）、非空文字和非白色底色单元格；拖过已经全部选中的区域可
  整块取消选择；
- 支持 `A1-B3` 这样的矩形范围，并按
  `A1、A2、A3、B1、B2、B3` 的顺序展开；
- 映射列表和 Excel 方案会将连续区域压缩显示为 `A1-B3`、`A1-A3`
  等简写；
- 新增映射时自动采用同名目标工作表，并让写入单元格跟随读取单元格；
- 添加、编辑、复制、删除映射规则；
- 不需要选择映射类型：两边单元格数量相同时按顺序对应，一个来源单元格
  可自动写入多个目标单元格；
- 将多单元格规则展开为逐项的“来源位置 → 目标位置”预览；
- 导入、导出业务人员可直接编辑的 Excel 映射方案，并可生成空白模板；
- “手动设置”和“Excel 方案”使用两个按钮切换页面，普通切换不会修改另一页；
- 手动页面通过“转换为 Excel 方案”生成方案，Excel 方案页面通过
  “转换为手动设置”应用
  方案，只有点击转换按钮时才会转换；
- Excel 方案中每组映射使用相邻两行表示：蓝色来源行、绿色目标行；
- Excel 方案预览支持直接编辑：单击工作簿会列出方案文件夹中的表格，
  单击工作表显示对应工作表，单击单元格打开可视化选择器；
- 双击工作簿打开文件浏览器，可选择默认文件夹之外的文件并显示绝对路径；
  双击工作表或单元格可手工输入；Enter/Tab 保存并移动，Esc 取消；
- Excel 方案页支持新增、复制和删除整组来源/目标行；
- Excel 方案表格底部始终保留一组空白来源/目标行，开始填写后自动创建
  正式映射，并继续补充下一组空白行；
- 选中映射组后可按 Delete 删除，右键可在上方/下方插入、复制或删除整组；
- “默认文件夹”默认使用方案所在文件夹，双击路径框或点击按钮即可修改；
- 执行前检查文件、工作表、单元格、重复目标和已有内容；
- 为目标工作簿生成新副本，原文件始终不修改；
- 支持 `.xls`、`.xlsx`、`.xlsm`，映射副本保持目标工作簿原扩展名。

Windows 电脑安装了 Microsoft Excel 时，程序会优先通过 Excel 本身打开完整
副本，并且只修改目标单元格的值。因此 `.xls`、`.xlsx`、`.xlsm` 的合并单元格、
字体、颜色、底色、边框、数字格式、行高列宽及页面布局均由 Excel 原生保留。
程序现在按“Microsoft Excel → WPS 表格 → Python 兼容模式”的顺序自动选择
写入方式。Excel 或 WPS 可用时，由办公软件原生打开副本并只修改单元格值；
两者均不可用时，`.xls` 使用 `xlutils` 保底并保持原扩展名及常规单元格样式。
纯 Python 保底方式无法完整保留旧版 `.xls` 中的公式、图表等高级对象。

Excel 方案表固定使用五列：

| 映射组 | 类型 | 工作簿 | 工作表 | 单元格 |
|---|---|---|---|---|
| 1 | 来源 | 来源.xlsx | 数据 | A1-B3 |
| 1 | 目标 | 目标.xlsx | 模板 | 同位置 |
| 2 | 来源 | 来源.xlsx | 汇总 | C3-C8 |
| 2 | 目标 | 目标.xlsx | 报表 | E3-E8 |

同一“映射组”必须正好包含一行“来源”和一行“目标”。`同位置`表示写入
单元格与读取单元格相同。工作簿可填写绝对路径，也可填写相对于 Excel 方案
文件所在文件夹的相对路径。`B3-B6`、`A1-D1`表示连续范围，`A1-B3`表示
左上角到右下角的矩形范围。

导入时也支持省略“映射组”和“类型”的精简三列表：

| 工作簿 | 工作表 | 单元格 |
|---|---|---|
| 来源.xlsx | 数据 | A1-B3 |
| 目标.xlsx | 模板 | 同位置 |

精简表按非空数据行自动识别为“来源、目标、来源、目标……”。

也可以只省略“映射组”，使用四列表。程序会根据“来源/目标”自动生成映射组：

| 类型 | 工作簿 | 工作表 | 单元格 |
|---|---|---|---|
| 来源 | 来源.xlsx | 数据 | A1-B3 |
| 目标 | 目标.xlsx | 模板 | 同位置 |

`ExcelMappingTool.exe` 是只保留可编辑映射表格的精简版本。在“类型”列按住
鼠标即可拖动一行或 Ctrl 多选的多行；拖动的只有工作簿、工作表、单元格三列，
映射组和来源/目标会根据放下后的行位置自动重新编号。右键或 Ctrl+C/Ctrl+V
可复制、粘贴所选行的后三列内容。

“手动设置”和“Excel 方案”按钮只切换页面，不会隐式转换或覆盖内容。点击
转换按钮才会同步另一页面。点击“预检查”或“开始映射”时，程序进行完整
检查并提示具体错误。

“Excel 方案”页面中的表格可直接编辑。“映射组”和“类型”由程序管理，
工作簿、工作表及单元格可双击修改。“导出为可编辑 Excel 方案”还可以生成
真正的 `.xlsx` 方案文件，业务人员可在 Excel/WPS 中批量修改后再导入。

## 构建 Windows EXE

推送到 GitHub 后，`Build Windows EXE` 工作流会在 Windows 环境中运行测试并
生成 `ExcelSummary.exe`、`ExcelMapper.exe` 和 `ExcelMappingTool.exe`。
在 Actions 运行页面底部分别下载对应的 Windows 构建产物。
